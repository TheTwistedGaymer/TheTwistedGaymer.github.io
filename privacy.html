Privacy Policy

This policy explains how the personal Windows application TTG Command Desktop handles Google Calendar data when its owner chooses to connect Google Calendar.

This is a draft privacy notice for a personal-use application. It must be reviewed and approved by the application owner before any public website is published.

Information accessed

With the owner's explicit consent, TTG requests Google's calendar.calendarlist.readonly and calendar.events.readonly permissions. These permit the app to read the calendar list and details of events the Google account can access, including event title, start/end time, all-day status, location, event identifiers and calendar category.

How information is used

Calendar data is used only to populate the owner's daily agenda, upcoming appointment indicators and household or finance reminders inside TTG Command Desktop. The app never creates, changes or deletes Google Calendar events.

Where information is stored

  • TTG stores an offline calendar cache as an ordinary local JSON file in its application directory on the owner's Windows PC. Calendar event details in this cache are not encrypted; Windows file permissions protect access to the owner's files.
  • The Google OAuth refresh token is encrypted with Windows DPAPI tied to the current Windows user and saved within the owner's LocalAppData directory, not within the web interface's local storage.
  • TTG keeps local tasks and notes in the native WebView2 profile on the PC; these do not come from Google Calendar.

Sharing, transfers and selling data

TTG does not operate an external calendar-data server. It communicates directly with Google's official services to authorise access and retrieve events. The developer does not intentionally collect, send or sell calendar data to third parties, nor use it for advertisements, analytics or AI-model training. Opening optional external websites from TTG is a separate user action governed by those websites' policies.

Retention and deletion

The calendar cache is updated when a successful sync completes. Existing cache data remains available when offline until refreshed or manually deleted. The owner can stop TTG, remove its local calendar cache and run the connector's disconnect command to erase the locally stored OAuth token. The owner can also revoke Google's authorisation from Google Account settings. Revocation stops future Google Calendar access.

Security

Google sign-in is performed in the system browser, never in a TTG-controlled embedded login. Tokens are never requested through ChatGPT messages. The application uses a local loopback callback during consent and read-only Google Calendar API requests over HTTPS. Anyone with access to the owner's unlocked Windows account or its files may be able to read local cached event data.

Google API Services User Data Policy

TTG's use of information received from Google APIs is limited to the functionality described here and is intended to comply with the Google API Services User Data Policy, including its Limited Use requirements where applicable.

Contact

Questions about the personal-use app may be directed to the owner's support email listed on the Google OAuth consent screen. The owner will decide whether to publish a contact address on this page.

Updates

This policy may change when the app's features or data handling change. An updated effective date will be shown here.
