TTG Command Desktop is a personal dashboard designed for a two-monitor Windows setup. It brings together daily planning, local notes, tasks and a read-only view of Google Calendar.

Not a publicly available app. This project is built for personal use on its owner's Windows computer. There is currently no public download or service to register for.

What it does

Daily Overview

See upcoming appointments, household reminders, local tasks and notes in one place.

Read-only Google Calendar

With explicit Google consent, the app reads available calendar lists and event details. It never changes or deletes Google Calendar entries.

Local Windows Interface

Runs as a native Windows application with WebView2. No developer-hosted calendar server is used.

Your data remains under your control

Authorisation uses Google's own OAuth sign-in. Calendar data is cached locally to support the Overview, and the Google refresh token is encrypted for the signed-in Windows user. Read the privacy policy for the full details.

Personal-use software. No paid access, subscription or advertisements are offered by TTG Command Desktop.
